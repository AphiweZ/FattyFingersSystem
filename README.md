# FattyFingers

A food ordering application. Users can log in, browse the available food
items, select what they want, and place an order.

## Features

- 🔐 **User login** — users sign in to place orders under their own account.
- 🍔 **Browse menu** — view the available food items to choose from.
- 🛒 **Select & order** — add food items and place an order.

## Tech stack

- **Java**
- Developed in **IntelliJ IDEA** (`.idea` project files included)

## Project structure

```
FattyFingers/
  .idea/            IntelliJ IDEA project settings
  FattyFingers/     Application source code
```

## Getting started

### Prerequisites

- [Java JDK](https://www.oracle.com/java/technologies/downloads/) (8 or later recommended)
- [IntelliJ IDEA](https://www.jetbrains.com/idea/) (Community edition is fine)

### Setup

1. **Clone the repo**
   ```
   git clone https://github.com/ahiwe/FattyFingers.git
   ```

2. **Open in IntelliJ IDEA**
   Use **File → Open** and select the `FattyFingers` folder — since the
   `.idea` folder is already included, IntelliJ will load the existing
   project configuration automatically.

3. **Run the app**
   Locate the main class (the entry point with a `main` method) in the
   project tree, right-click it, and choose **Run**.

## How it works

1. A user logs in with their account.
2. They browse the list of available food items.
3. They select the items they want.
4. They place the order.
